Decisions on this page come from the local AgntID stand-in, the same code as cleargate bank --stub, with a scripted support team and no model. The bank's own payee check is off, so only the agent layer stands between the caller and the money. Each run writes a signed record and is checked with verify.py before the result comes back.

The agent acts. AgntID decides. The engineer signs.
